# Aset visual SIGAP

Foto `bridge.png`, `road.png`, `water.png`, `irrigation.png`, dan `lighting.png` dibuat menggunakan imagegen untuk demonstrasi frontend SIGAP. Semua menggambarkan infrastruktur pedesaan fiktif di Indonesia. Tidak digunakan sebagai bukti kejadian nyata. Label foto simulasi ditampilkan dalam antarmuka.

Font IBM Plex Sans (400, 500, 600, 700) dan IBM Plex Mono (400, 500, 600) diunduh dari Google Fonts. Salinan stylesheet sumber ada di `fonts-google.css`; stylesheet lokal ada di `fonts.css`. Copyright 2019 IBM Corp. All rights reserved. Lisensi SIL Open Font License 1.1; lihat `fonts-LICENSE.txt`.

Peta simulasi dan ikon merupakan SVG/CSS yang dibuat langsung untuk proyek, tanpa ketergantungan peta eksternal.
